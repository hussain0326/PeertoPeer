# Peer-to-Peer Distributed System

A group project from my bachelor’s studies to practice distributed systems in Java. This project demonstrates how peers connect, communicate, and coordinate through a central server using UDP.

# Features

Server sends ping messages every 20 seconds to check if peers are online

Peers respond if available; non-responding peers are removed

First peer acts as leader and manages the peer list

Simple chat feature between server and peers

# Tech

Java, UDP, ArrayList for peer management, multithreading for concurrent requests
